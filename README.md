# 青石五笔输入法

**小狼毫 Weasel 的五笔定制版：内核仍是 Rime，外面补上了五笔真正需要的东西。**

小狼毫本身是一套通用输入法框架，五笔只是其中一个方案。青石沿用它成熟的 Windows TSF 接口和 Rime 内核，把五笔的码表、词序、外观和游戏兼容重新做了一遍，并补了一个独立的图形设置中心。

当前版本 **v2.0.0**。

本版改进四码无候选后的处理：空格或回车会清除错码，继续输入字母会从当前字母重新编码；无论提示音是否开启都生效。安装包约 24.8 MB，保留三套方案、自定义词条与词序、配置备份和快捷键设置。

## 一、比小狼毫改进了什么

### 1. 改设置不再重新部署（热加载）

这是青石最核心的改动，也是日常感受最明显的一条。

小狼毫的配置模型是「编译式」的：改任何 YAML，都要跑一遍 `WeaselDeployer.exe /deploy`，重建 `build/` 下的 prism、table、reverse 等产物。慢则十几秒，占内存，而且部署期间输入法不可用。

青石把配置分成两类：

| 改什么 | 小狼毫 | 青石 |
| --- | --- | --- |
| 配色、字体、字号、圆角、横排／竖排 | 部署 | **热加载，150–300ms，不重启服务** |
| 每页候选数、标点风格、Shift 行为 | 部署 | **热加载** |
| 候选调序（置顶／取消固顶） | 不支持 | **写独立规则文件 + 热加载** |
| 换码表、换词库 | 部署 | 部署（这类改动本来就必须重建索引） |

做法上有三层：

1. **服务端不读部署缓存，直接读最新的 `weasel.custom.yaml`。** 小狼毫的样式来自 `build/weasel.yaml`，不部署就永远是旧值；青石在读取时把最新配置覆盖上去。
2. **客户端每次应答都同步样式。** 候选窗是宿主进程里长期复用的窗口，以前只在「建窗」时拿一次样式，所以设置里换了配色、旧候选框还是旧颜色。现在每次按键都会比对样式，一旦不同就重建布局、重新初始化字体并重绘。
3. **样式变化会强制补一次重绘。** 内容没变时 Rime 会跳过刷新，只改配色不按键的话画面不会动，所以样式变更单独触发一次。

结果：换配色、换字体、切横竖排，**下一次按键就生效，不用重启输入法，正在打的字也不会丢**。

### 2. 候选框里直接调词序

小狼毫只能靠词频和词库权重间接影响顺序，改一次要动词库、要部署，还会被后续学习覆盖。

青石在候选装配流水线的最后加了一层独立规则：

- 在候选上**右键 → 置顶／取消固顶**，或按 `Ctrl＋数字` 直接把第 N 个候选提到第一。
- 规则写到 `shadow_<方案>.yaml`，**不改原码表、不触发部署、不受学习衰减**。
- 规则按**编码**独立：改 `wqiy` 的顺序，不影响其它编码。
- 删掉某条规则，那个编码立刻回到词库原本的顺序。

设置中心的「自定义词序」页可以查看、删除这些规则，也可以直接写。

### 3. 严格固定词序

Rime 的词典写了 `sort: original` 也不代表顺序固定——只要 `translator/enable_user_dict` 没显式关掉，引擎默认会启用用户词典学习，选得多的词会慢慢往前跑，用户会觉得「顺序自己在变」。

青石为三套五笔方案明确关闭了自动学习、自动造词和造句，`*.userdb` 里的历史学习记录不再参与排序：

- 反复选后序候选，不会因为选得多而自动提前。
- 自定义词条和手动词序仍按指定顺序优先。
- 原码表、自定义词条、历史学习文件都不删除，只是不参与排序。

验证方式：三套方案各反复选择后序候选 40 次，候选列表保持不变。同时逐项核对了随包码表、发布版码表与本机码表，词条和相对顺序一致。

### 4. 游戏里能打字

小狼毫在《英雄联盟》《CS2》这类带反作弊的游戏里切不出输入法，原因不在 Rime，而在 Windows 的加载规则：

- **带反作弊的游戏只加载系统目录下的输入法 DLL。** 装在小狼毫 runtime 目录里的 `weaselx64.dll` 压根不会被加载，日志里连 `DllGetClassObject` 都不会出现。
- 青石的安装包把 TSF 组件装进 `C:\Windows\System32`，并**从 System32 那份重新注册**，`InprocServer32` 直接指向系统目录。
- 附带 IMM 兼容组件 `qingshi_game.ime`，给只支持 IMM 的老式游戏兜底。
- **候选窗按宿主意愿让位**：《英雄联盟》会自己画候选列表，青石读到宿主确实消费了候选数据就把绘制权让出去；宿主声明要画却没真画时，再退回本地候选窗，避免出现两个候选框。
- 安装与卸载会清理卸载残留的「半死」注册项（TIP 键、排序条目、直接切换快捷键），这类残骸会让新起的进程整条线程都拿不到输入法。

已在《英雄联盟》训练模式实测：实体键盘输入能弹出候选词，中文正常上屏。

### 5. 图形设置中心

小狼毫只有命令行部署器和一堆 YAML。青石把常用项做成了独立界面（Windows 原生界面，随安装包一起，不需要另装 Python 或 Qt）：

- 方案：三套五笔一键切换，设为默认。
- 输入习惯：简繁、全半角、中英文标点、Shift 键行为、Shift＋字母直接输出大写。
- 候选：每页数量、横排／竖排、内嵌编码、字体、字号、圆角。
- 外观：6 套配色（青石蓝白、水墨灰、护眼豆绿、暖阳橙、莓果红等），带实时预览。
- 词库：码表规模、导入 TXT 码表（导入前自动备份）。
- 词条／词序：见上文。
- 快捷键：点击录入主键与备用键，检查冲突、清除或恢复默认，三套方案共用。
- 备份与更新：配置导入导出、检查更新。

### 6. 配置导入导出

设置中心 →「备份与更新」可以把配置导出成单个 `.qingshi.zip`，换机器或重装后导回去：

- 外观、方案选择、候选数量、输入习惯。
- 自定义词条、自定义词库、自定义码表（包括自己加的 `.dict.yaml` 和方案配置）。
- 各方案的手动词序、固顶规则。
- 自定义快捷键，包括主键和备用键。

导入时校验文件清单、路径和 SHA-256，先自动备份本机配置再写入，写入失败会回滚。输入日志、`*.userdb` 学习库、注册表信息不进入备份。云端账号与同步暂不提供。

### 7. 自动检查更新

可手动检查，也可开启自动检查：登录 Windows 或打开设置时检查，每天最多一次。发现更高的正式版本后提示前往官方发布页，**不会自动下载安装**。

### 8. 四码无候选提示音

五笔打满四码却一个候选都没有，基本就是打错了（码位错了或者词库里没这个词）。青石会在这时响一声，不用盯着候选窗才发现打空。

- 在「常用设置 → 候选设置」里开关，**默认开启**。
- 同一个编码只响一次：接着按第五个键或方向键不会连环响；退格、上屏后重新打错会再响。
- 只在确实吃下按键之后判断，不会在英文输入或宿主自己处理按键时误响。

### 9. 四码唯一时自动上屏

打满四码只剩一个候选时，直接上屏，省掉那一次空格。

- **默认关闭**。它会改变输入节奏——习惯「打完看一眼再按空格」的人会觉得字自己跳上去了，所以做成可选。
- 开关在「常用设置 → 候选设置 → 四码唯一时自动上屏」。
- 只认「正好 4 码 + 唯一候选」：1–3 码的简码一律不动，避免把简码词误上屏。
- 和上面那条正好互补：**有唯一解就直接出，无解就响一声**。

## 二、三套五笔方案

| 方案 | 说明 |
| --- | --- |
| 五笔 86 | 王码 86 版原表，词库取自极点官方原版（极爽 4.3） |
| 五笔 98 | 98 版码元体系原表 |
| 新世纪五笔 | 2008 新世纪版原表 |

码表按原始条目顺序整理，过滤非法编码（只保留 a–y、1–4 码）并去重，权重统一为 0，顺序由码表本身决定。码表与个人扩展分开保存，改词条、调词序都不会写回原码表。

## 三、快捷键

在设置中心的「快捷键」页点击按键框后，按下想使用的组合键；Esc 取消录入。「应用」会更新配置并重启输入法服务。每项可设置主快捷键和备用键，也可清除或恢复默认。冲突或系统保留组合不会保存。下表列出默认按键。

数字选词、空格上屏、Esc 清空和 PgUp / PgDn 保留为基础输入键；Win＋空格等 Windows 系统快捷键不在输入法内修改。Ctrl＋数字及部分 Ctrl＋Shift＋数字用于候选调序。

| 操作 | 快捷键 |
| --- | --- |
| 切换中英文 | Shift |
| 选第二／第三候选 | `;` / `'` |
| 候选置顶 | 候选上右键，或 `Ctrl＋数字` |
| 简繁切换 | `Ctrl＋Shift＋F` / `Ctrl＋Shift＋T` |
| 全角／半角 | `Shift＋空格` |
| 中英文标点 | `Ctrl＋.` |

## 四、安装与使用

前往 **[GitHub Releases](https://github.com/Vincentkeio/qingshi-wubi/releases/latest)** 下载 `QingshiSetup.exe`。

- 支持 Windows 10 / 11 x64。
- 安装后按 `Win＋空格` 切到「青石五笔」；升级后已经打开的程序需要重开一次（Windows 的 DLL 加载规则，不是青石的问题）。
- 右键托盘图标进设置中心；在 Windows「设置 → 应用」中卸载，可选择保留个人数据。
- 升级保留配置和词条；安装失败会恢复上一版注册与运行时记录。
- Release 附带 `QingshiSetup.sha256` 与 `release-manifest.json`，可核对安装包和构建信息。
